# Technical Project Management Dashboard | Frontend Practice

## Project Overview

This repository documents my early hands-on experience with frontend web development, dating back to July 2024.

The primary project involved building the frontend interface of a Technical Project Management dashboard using HTML, CSS, and JavaScript. The repository also includes practical exercises involving DOM manipulation, JSON data handling, and asynchronous data retrieval.

## What I Worked On

- Developed the basic layout of a project management dashboard.
- Designed navigation elements, sidebar components, a project description section, and a notice board.
- Practiced CSS styling, positioning, and layout techniques.
- Explored DOM traversal and manipulation using JavaScript.
- Worked with JSON data using XMLHttpRequest and the Fetch API.
- Practiced dynamically generating HTML elements from JSON responses.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- JSON

## Project Structure

- `index.html` / `index2.html` – Dashboard interface development.
- `style.css` / `style2.css` – Dashboard styling.
- `project.json` – Project and task data.
- `index3.html` – DOM manipulation exercises.
- `script.js` – JavaScript and JSON handling experiments.
- `sample2.html` / `sample2.js` / `sample2.json` – JSON data retrieval and rendering.
- `products.json` – Sample product data for JSON practice.
- `assets/` – Images and icons used in the interface.

## Repository Status

This repository is archived and preserved as a record of my early frontend development learning and practical experience from July 2024.

It contains dashboard UI experiments and JavaScript practice exercises developed while exploring core web development concepts. The project is not actively maintained, but the source code remains publicly available for reference.
